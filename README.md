A GTA 6 meme for make.fun's "Post a GTA 6 meme on X" bounty. The make.fun ghost is
the most wanted fugitive in Vice City — five stars, dead or cashed out — while
everyone else is still grinding virtual GTA money. The ghost already cashed out.

The meme itself is the X post this repo points to: `POST.json` names the post, and
`main.ts` copies it to `/output` for the grader. The picture (`meme.png`) is an
AI-generated Vice City scene: the make.fun ghost lounging on a pink convertible
while a gamer grinds in the background. Earlier poster drafts and the comparison
behind the pick live in `drafts/` and `DRAFT-NOTES.md`.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
